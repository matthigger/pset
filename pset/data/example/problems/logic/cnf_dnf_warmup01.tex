\begin{enumerate}[i]

    \item

    Give a logical expression with variables p, q, r that is true only when p is False, q is True, and r is False.

    \sol{
    $\neg p \wedge q \wedge \neg r$
    }

    \item

    Give a logical expression with variables p, q,r that is false only when p is False, q is True, and r is False.
    (HINT: how does this expression relate to the solution directly above?)

    \sol{We seek the negation of the first part of the problem:
    $\neg (\neg p \wedge q \wedge \neg r) =
    p \vee \neg q \vee r$
    where we've applied DeMorgan's law.
    }

\end{enumerate}
